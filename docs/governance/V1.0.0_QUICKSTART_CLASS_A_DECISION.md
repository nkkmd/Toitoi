# v1.0.0 Developer Quick Start Class A Decision

**Status:** normative registry amendment  
**Effective from:** v1.0.0 candidate  
**Decision date:** 2026-07-27

This document is an explicit documentation-governance decision under `DOCUMENTATION_LANGUAGE_POLICY.md`. It amends the Class A registry for v1.0.0 by adding:

- `docs/quickstart/README.md`
- `docs/quickstart/TRANSPORT_QUICKSTART.md`
- `docs/quickstart/INDEXER_API_QUICKSTART.md`
- `docs/quickstart/EDGE_AI_QUICKSTART.md`

These files are public developer entry points and must remain bilingual, with English followed by equivalent Japanese. The transport quick start must cover Nostr, Lingonberry, and ATProto without treating any transport identity as Canonical identity.

This amendment remains authoritative until the rows are consolidated into the main policy registry or replaced by a later explicit governance decision.
