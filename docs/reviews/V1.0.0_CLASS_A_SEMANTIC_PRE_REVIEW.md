## Pre-review findings

No known material semantic divergence was identified in the repository-controlled checks and targeted comparison performed for this pre-review.

The following points require explicit human confirmation because automated comparison cannot determine requirement strength or contextual equivalence:

1. `MUST`, `SHOULD`, prohibitions, and release-blocking language have equivalent strength in Japanese.
2. Security warnings concerning credentials, private keys, sensitive observations, and OAuth/OIDC limitations are not weakened.
3. `schemaVersion: "0.1.0"` is consistently described as the stable wire-schema identifier for repository release `v1.0.0`.
4. Native v1 and the explicit `v0.9.0` compatibility profile are not conflated.
5. Canonical identity is never inferred from transport identity, similarity, vocabulary mapping, or semantic relation.
6. AI annotation acceptance remains distinct from publication approval; the minimum reference contract requires separate auditable decisions but does not require different human actors.
7. Rollback is described as verified pre-migration backup restoration into a separate root; reversible `down()` migrations are not claimed.
8. Nostr, Lingonberry, and ATProto commands, limitations, and authorization warnings are operationally equivalent.
9. Pilot, hosted-environment, live-transport, and real local-model limitations remain visible in both languages.
